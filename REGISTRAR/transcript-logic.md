# Transcript Logic

## Purpose

The transcript logic framework defines how completed competencies, micro-credentials, courses, certificates, and pathways are recorded.

The transcript translates competency evidence into institutional academic records.

---

## Transcript Record Fields

Each transcript record should include:

- learner name or identifier
- student ID
- course code
- course title
- credit value
- micro-credentials completed
- mastery status
- grade or pass/fail result
- completion date
- Faculty-of-Record approval
- registrar approval
- evidence archive reference

---

## Micro-Credential Transcript Mapping

A micro-credential may be recorded when:

- learning outcome is defined
- engagement hours are documented
- evidence artifact is submitted
- assessment rubric is applied
- Faculty-of-Record approves completion

---

## Course Transcript Mapping

A course may be recorded when:

- all required micro-credentials are complete
- required credit hours are satisfied
- course learning outcomes are met
- final portfolio artifact is approved
- Faculty-of-Record submits final status
- registrar records completion

---

## Transcript Principle

The transcript is not merely a list of completed content.

It is an academic record of faculty-reviewed competency.
