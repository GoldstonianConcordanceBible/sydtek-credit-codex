# Time and Effort Rubric

## Purpose

The Time and Effort Rubric documents the expected student workload for each micro-credential and course.

This framework supports credit-hour transparency and accreditation-readiness.

---

## Micro-Credential Workload

Each micro-credential equals approximately 11.25 total student engagement hours.

Recommended distribution:

| Activity Type | Estimated Hours |
|---|---:|
| Direct instruction or guided media | 1.5 |
| Reading, research, or source review | 2.0 |
| Applied practice or lab work | 3.0 |
| Reflection or written response | 1.5 |
| Artifact creation or portfolio work | 2.0 |
| Review, revision, and submission | 1.25 |
| Total | 11.25 |

---

## Course Workload

A standard SydTek course includes 12 micro-credentials.

| Unit | Hours |
|---|---:|
| 1 micro-credential | 11.25 |
| 12 micro-credentials | 135 |
| Standard course equivalent | 3 credits |

---

## Documentation Requirement

Each micro-credential should document:

- estimated hours
- learning activities
- student work product
- required artifact
- assessment method
- faculty review status

---

## Completion Rule

Time spent does not equal mastery.

Evidence submitted does not equal mastery.

Mastery is recognized when time, outcome, evidence, rubric performance, and faculty approval align.
