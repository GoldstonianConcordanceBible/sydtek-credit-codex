# Gemach AI Trading Agent

## DeFi Adapter Infrastructure for Gemach AI

The Gemach AI Trading Agent is the DeFi Adapter within the Gemach AI Protocol Interface.

This agent translates natural language into structured DeFi intent, especially for GDex.pro operations, wallet-linked trading activity, treasury monitoring, and educational interpretation.

---

# Core Purpose

The Trading Agent helps users understand and prepare DeFi actions such as:

- perpetual futures
- long and short positions
- leverage awareness
- portfolio tracking
- wallet activity summaries
- treasury-linked trading records
- referral-based ecosystem growth

This repository does not custody assets or execute transactions by itself.

It prepares, explains, labels, and documents DeFi activity.
