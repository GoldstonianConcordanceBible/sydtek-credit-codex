# GitHub Evidence Framework

## Purpose

GitHub repositories may function as reviewable evidence within SydTek’s competency-based education framework.

GitHub supports:

- version control
- public transparency
- timestamped contribution tracking
- collaborative work
- documentation review
- portfolio development

---

## Acceptable GitHub Evidence

Examples include:

- repositories
- commits
- pull requests
- documentation
- research archives
- datasets
- code samples
- technical frameworks
- academic artifacts
- portfolio projects

---

## Review Requirements

GitHub activity alone does not automatically equal competency.

Faculty review must evaluate:

- relevance to learning outcome
- quality of contribution
- originality
- technical accuracy
- documentation quality
- reflection and explanation

---

## Documentation Requirements

Learners should document:

- repository URL
- project purpose
- learning outcome alignment
- contribution summary
- evidence screenshots or archive
- reflection statement

---

## GitHub Principle

GitHub provides transparent evidence of contribution, iteration, and applied competency.
