# Course Learning Outcomes

## Purpose

Course Learning Outcomes define what a learner must demonstrate by completing a course.

Each course contains 12 micro-credentials and normally equals 3 credit hours.

---

## Course Outcome Requirements

Each course must include:

- course title
- course code
- credit value
- course description
- prerequisites, if applicable
- course learning outcomes
- required micro-credentials
- evidence requirements
- assessment methods
- Faculty-of-Record
- final portfolio artifact

---

## CLO Template

### CLO 1 — Conceptual Understanding

Learners will explain key concepts, vocabulary, frameworks, or theories in the course area.

### CLO 2 — Applied Practice

Learners will apply course concepts through labs, projects, demonstrations, or field activities.

### CLO 3 — Evidence Production

Learners will produce artifacts that demonstrate measurable competency.

### CLO 4 — Analysis and Reflection

Learners will analyze their work, evaluate decisions, and reflect on learning outcomes.

### CLO 5 — Communication

Learners will present, document, or publish course-level learning clearly.

### CLO 6 — Portfolio Integration

Learners will organize course artifacts into a portfolio or evidence archive.

---

## Course Completion Rule

A course is complete only when:

- all required micro-credentials are completed
- required engagement hours are documented
- required artifacts are submitted
- course learning outcomes are met
- assessment rubric is applied
- Faculty-of-Record approves completion
- registrar records the outcome
