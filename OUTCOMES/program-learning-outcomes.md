# Program Learning Outcomes

## Purpose

Program Learning Outcomes define what learners should demonstrate by completing a full academic program or pathway.

Each program must map to the Institutional Learning Outcomes.

---

## Required Program Outcome Structure

Each program should define:

- program title
- program level
- program purpose
- target learner profile
- required credits
- required courses
- program learning outcomes
- assessment methods
- capstone or portfolio requirement
- faculty review process

---

## Program Learning Outcome Template

### PLO 1 — Disciplinary Foundation

Learners will demonstrate foundational knowledge in the program discipline.

### PLO 2 — Applied Competency

Learners will apply program knowledge through projects, labs, fieldwork, or public artifacts.

### PLO 3 — Research and Evidence Use

Learners will evaluate and apply evidence appropriate to the discipline.

### PLO 4 — Communication and Documentation

Learners will communicate program knowledge through written, oral, visual, or technical formats.

### PLO 5 — Ethical and Professional Practice

Learners will demonstrate ethical judgment and professional responsibility.

### PLO 6 — Portfolio Demonstration

Learners will produce a portfolio demonstrating program-level mastery.

---

## Mapping Requirement

Each PLO must map to:

- at least one Institutional Learning Outcome
- one or more required courses
- assessment evidence
- faculty review criteria

---

## Program Completion Rule

A program is complete only when the learner has:

- completed required credits
- satisfied course requirements
- met program learning outcomes
- submitted required evidence
- completed portfolio review
- received faculty or committee approval
