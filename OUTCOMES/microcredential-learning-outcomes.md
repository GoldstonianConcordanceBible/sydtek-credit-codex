# Micro-Credential Learning Outcomes

## Purpose

Micro-Credential Learning Outcomes define the smallest measurable unit of demonstrated learning.

A micro-credential is worth approximately 0.25 credit hours and represents approximately 11.25 total student engagement hours.

---

## Required Micro-Credential Fields

Each micro-credential must include:

- micro-credential title
- micro-credential code
- parent course
- credit value
- estimated engagement hours
- learning outcome
- competency category
- required learning activity
- required evidence artifact
- assessment rubric
- mastery threshold
- faculty reviewer
- portfolio location
- transcript mapping

---

## Micro-Credential Outcome Template

By completing this micro-credential, the learner will be able to:

1. explain the core concept or skill
2. apply the concept or skill in context
3. produce a reviewable evidence artifact
4. reflect on the learning process
5. connect the artifact to the broader course outcome

---

## Acceptable Evidence

Evidence may include:

- written response
- video reflection
- GitHub commit
- blockchain transaction
- portfolio artifact
- research note
- case study
- quiz or exam
- field documentation
- presentation
- design artifact
- code sample
- published post

---

## Mastery Rule

A micro-credential is not complete because an artifact exists.

A micro-credential is complete when the artifact demonstrates the stated outcome at or above the required mastery threshold.

Faculty review is required for academic recognition.
