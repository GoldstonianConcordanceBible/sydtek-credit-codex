## What This Is

Each Faith Adapter maps a distinct theological, philosophical, or worldview tradition onto the shared CBE (Curriculum-Based Education) infrastructure. Adapters are:

- **Additive** — they extend shared infrastructure without overriding it
- **Non-prescriptive** — no adapter imposes doctrine on any other
- **AI-readable** and **LLM-routable** — designed for machine ingestion and agent routing
- **GitHub-native** — versioned, forkable, permanently archived
- **50-year horizon documents** — not trend-responsive

## Adapter Architecture

Every adapter follows a shared five-part structure:

```
1. Purpose               — target institution and tradition
2. Optional Components   — modular doctrinal, textual, and practice elements
3. Formation Outcomes    — CBE-mapped competency statements
4. Adapter Principle     — single-sentence infrastructure alignment statement
5. Notes for Implementation — differentiation and cross-adapter integration
```
