# Faculty Review Process

## Purpose

The Faculty Review Process ensures that public evidence is translated into academic recognition through qualified evaluation.

Public verification supports review.

Faculty assessment determines academic credit.

---

## Review Steps

1. Learner completes required activity.
2. Learner submits required evidence artifact.
3. Learner maps artifact to the stated learning outcome.
4. Faculty reviewer evaluates the artifact using the approved rubric.
5. Faculty reviewer assigns mastery level.
6. Learner revises if required.
7. Faculty-of-Record approves completion.
8. Registrar records academic progress.

---

## Faculty Review Requirements

Each review should document:

- learner name or ID
- course code
- micro-credential code
- evidence link
- learning outcome
- rubric score
- reviewer name
- review date
- completion status
- revision notes, if applicable

---

## Review Outcomes

Possible outcomes:

- Approved
- Approved with distinction
- Revision required
- Not approved
- Academic integrity review required

---

## Academic Recognition Rule

No public artifact, blockchain record, GitHub commit, or YouTube activity becomes official academic credit until reviewed and approved by the designated faculty reviewer.
