# Portfolio Assessment Framework

## Purpose

The portfolio assessment framework defines how student artifacts are organized, reviewed, and validated as evidence of competency.

The portfolio functions as a cumulative academic record of demonstrated learning.

---

## Portfolio Contents

A student portfolio may include:

- written assignments
- video reflections
- GitHub repositories
- blockchain records
- DAO participation records
- research artifacts
- field documentation
- presentations
- published codices
- datasets
- capstone projects
- verifiable credentials

---

## Portfolio Review Categories

Each portfolio should be reviewed for:

1. Completeness  
2. Outcome Alignment  
3. Evidence Quality  
4. Reflection and Integration  
5. Academic Integrity  
6. Technical Accessibility  
7. Long-Term Preservation  
8. Public or Institutional Reviewability

---

## Portfolio Milestones

Recommended milestones:

| Stage | Review Point |
|---|---|
| Micro-Credential | Artifact review |
| Course | Course portfolio review |
| Certificate | Certificate portfolio review |
| Associate-Level | General education and pathway review |
| Bachelor-Level | Concentration and capstone review |
| Master-Level | Advanced research or applied systems review |
| Doctoral-Level | Original contribution review |

---

## Portfolio Principle

The portfolio is not a scrapbook.

It is a structured evidence archive mapped to learning outcomes, assessment rubrics, and faculty review.
